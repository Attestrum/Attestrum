This dataset is the **sample-100BT** subset of **FineWeb-Edu**, a corpus of 97,270,686 educational web pages filtered from FineWeb — CommonCrawl-derived web text — by **Hugging Face** using an educational-quality classifier (Penedo et al., 2024, *The FineWeb Datasets: Decanting the Web for the Finest Text Data at Scale*; Lozhkov et al., 2024, *FineWeb-Edu*).

- **Source:** [`HuggingFaceFW/fineweb-edu`](https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu) (Hugging Face), subset `sample/100BT`, revision `87f09149ef4734204d70ed1d046ddc9ca3f2b8f9`.
- **Original work:** the dataset is released by Hugging Face under the [Open Data Commons Attribution License (ODC-By) v1.0](https://opendatacommons.org/licenses/by/1-0/), and its use is additionally subject to the [CommonCrawl Terms of Use](https://commoncrawl.org/terms-of-use). The underlying pages were crawled by CommonCrawl from the public web; copyright in each page remains with its original author.
- **Modifications:** none to the sealed content. **Only the `text` column bytes of each row are sealed** — one row per leaf, byte-for-byte, no rendering, filtering, or normalization. The upstream metadata columns (`id`, `dump`, `url`, language and quality scores) are not part of the sealed bytes; each leaf's `source_uri` carries the row's upstream `id` for traceback. This distribution publishes only the cryptographic manifest (per-row digests + Merkle root) and its signature, not the page texts themselves.
